# Human vs. AI-Generated Code

## Dataset Summary

This dataset is a large-scale collection of human-written and LLM-generated code designed to study differences in defect distribution, code quality, and security characteristics between human developers and modern AI code assistants.

It contains paired implementations of the same function across multiple authorship sources, spanning Python and Java, two widely adopted programming languages with distinct typing systems, paradigms, and software engineering practices.

The dataset supports research in code quality analysis, secure code generation, vulnerability detection, software engineering, program analysis, and evaluation of large language models for code.

## Languages

## Dataset Structure

Each data instance corresponds to a single function and contains the following fields:

- `docstring`: Original documentation describing the function’s behavior
- `human_code`: Function implementation written by a human developer
- `chatgpt_code`: Function implementation generated by ChatGPT (gpt-3.5-turbo, April 2023)
- `deepseek_code`: Function implementation generated by DeepSeek-Coder-Instruct (33B)
- `qwen_code`: Function implementation generated by Qwen2.5-Coder-Instruct (32B)

Each function has one human-written implementation and three AI-generated implementations.

## Data Sources

The dataset extends the [HMCorp](https://doi.org/10.1145/3705300) dataset, which was constructed from the Python and Java subsets of the [CodeSearchNet](https://github.com/github/CodeSearchNet) dataset.

CodeSearchNet is a widely used benchmark consisting of documentation–code pairs mined from public, non-forked GitHub repositories, sorted by popularity, and is commonly used to train and evaluate code-related language models.
